# Pipeline reliability configuration

## AI Attribution Block

AI-assisted configuration templates. This directory does not alter GitHub Actions, GitOps, IAM, ArgoCD deployment authority, database migration execution, or any live monitoring environment.

`observability/` contains Prometheus rules, Alertmanager routing placeholders, OpenTelemetry Collector configuration and progressive-delivery verification criteria. Apply them only through approved platform change management after replacing `REPLACE_WITH_*` placeholders and validating against the installed component versions.
